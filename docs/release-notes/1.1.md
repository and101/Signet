**New**

- **Direct install (beta).** Install apps the way a computer does, using LocalDevVPN and a pairing file from iloader. No install certificate is needed, and Signet can update itself.
- **Updates.** New versions from your sources appear in the Library. Signing an update reuses the last version's settings, tweaks and icon.
- **Signet's own source** is added by default, so Signet updates appear in the Library too.
- **More signing options.** Liquid Glass or the classic look, light or dark mode, ProMotion and Game Mode. Renaming an app now changes its name in every language.
- **Remove individual extensions and frameworks**, and inject tweaks into extensions.
- **Icons.** Choose one from Files or from the app's own alternate icons.
- **Rename rules** give apps a bundle ID or name automatically whenever they're signed.
- **Custom entitlements.** Sign with your own entitlements file.
- **Export without signing.** Save a modified IPA to sign elsewhere.
- **Send a certificate to LiveContainer.**
- **Sources** show news, featured apps and screenshots.
- **Library.** Select several apps to delete them.
- **Installs** keep running in the background and show iOS's install progress.
- **Acknowledgements** in Settings list every open source component.
- Signet can now be translated.

**Improved**

- Links from websites ask before adding a source or downloading an app.
- Backing up certificates needs Face ID, Touch ID or your passcode.
- Damaged or malicious IPAs, tweaks and backups are rejected instead of crashing Signet.
- Shorter, clearer text throughout.

**Requirements**

iOS 17 or later. Direct install needs LocalDevVPN and a pairing file made on a computer.

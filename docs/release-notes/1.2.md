**New**

- **Simpler layout.** Three tabs: Library, Sources and Settings. Certificates now live in Settings.
- **Settings in groups.** Signing, Installing, Downloads, Data and About each have their own section.
- **GitHub updates in the Library.** New releases from tracked repos appear next to source updates.
- **Simpler Sign screen.** Certificate and Customize come first. Tweaks, removals, appearance, entitlements and options are under Advanced.
- **Signing options in groups**, on the Sign screen and in Default Options.
- **Install progress bar** for both install methods.
- **Allow HTTP.** Sources and downloads use HTTPS by default. Turn this on to allow plain http.
- **iPad sidebar** on iOS 18 and later.
- **New icons** that match iOS.
- The Library warns you when your default certificate has expired or been revoked.

**Improved**

- Stricter checks on IPAs, tweaks, icons and backups.
- The install server can resume interrupted downloads.
- Going back from a certificate's details now returns to the list.

**Requirements**

iOS 17 or later. Direct install needs LocalDevVPN and a pairing file made on a computer.

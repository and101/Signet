**Improved**

- Signatures and entitlements now match Apple's own format more closely.
- Signing fails with a message if the signature can't be made, instead of producing an app that won't install.
- Sources with one app no longer list it twice.

**Fixed**

- Some custom entitlements files could crash Signet or produce an app that won't install.
- Cancelling a download just as it finishes no longer adds the app.
- A certificate's nickname can't be left blank.
- Versions typed with a comma are saved with a dot.

**Requirements**

iOS 17 or later. Direct install needs LocalDevVPN and a pairing file made on a computer.
